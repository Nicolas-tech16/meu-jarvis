01 / Entenda o projeto

O que você vai construir?

Um projeto realista para computador. Não existe um único botão que crie o JARVIS dos filmes: você combina componentes, testa cada um e só depois conecta tudo.

🎙️

Ouvir você

Captura áudio do microfone e transforma fala em texto. Na primeira versão, você pode digitar os comandos para simplificar.

🧠

Raciocinar com IA

Envia a mensagem a um modelo de linguagem por uma API e recebe uma resposta contextualizada.

🔊

Responder em voz

Um mecanismo de texto-para-fala lê a resposta em voz alta. A voz e a qualidade dependem do serviço escolhido.

🖥️

Controlar o PC

Abre programas e páginas permitidas por funções específicas, em vez de dar acesso irrestrito ao computador.

🧩

Adicionar habilidades

Depois, acrescente hora, notas, lembretes, pesquisa, arquivos e integrações — uma habilidade por vez.

🛡️

Manter controle

Proteja a chave da API, peça confirmação para ações importantes e não execute texto arbitrário como comando do sistema.

02 / Preparação

Materiais e ferramentas

Você pode fazer a primeira versão sem comprar equipamentos especiais. Alguns serviços de IA cobram por uso e podem exigir conta.

Obrigatório

  • Computador com Windows, macOS ou Linux
  • Python 3.11 ou 3.12 recomendado
  • Editor de código, como VS Code
  • Internet para usar uma API online

Para voz

  • Microfone (o do notebook serve)
  • Caixas de som ou fones
  • Biblioteca de reconhecimento de fala
  • Biblioteca de síntese de voz

Contas e custo

  • Uma API de IA compatível com o SDK escolhido
  • Verifique preços, limites e métodos de pagamento
  • Alternativa: modelo local, se seu PC suportar
Importante sobre custo: o código de exemplo usa uma API online. Ela pode não ter uso gratuito e os preços mudam. Defina limites de gasto no painel do provedor. Não coloque sua chave de API em sites públicos, repositórios ou vídeos.
03 / Mão na massa

Tutorial passo a passo

Siga na ordem. Testar cada fase separadamente torna muito mais fácil descobrir onde algo deu errado.

1

Instale o Python e o editor

Baixe Python em python.org/downloads. No Windows, marque “Add Python to PATH” durante a instalação. Instale o Visual Studio Code e a extensão Python.

Abra um terminal e confira:

Terminal
python --version

Se o comando não funcionar no Windows, tente py --version. Se aparecer uma versão, está pronto.

2

Crie a pasta do projeto

Crie uma pasta chamada jarvis. Abra essa pasta no VS Code. Abra o terminal integrado e crie um ambiente virtual para manter as dependências isoladas.

Windows (PowerShell)
py -m venv .venv
.\\.venv\\Scripts\\Activate.ps1

Se o PowerShell bloquear a ativação, você pode usar o terminal Prompt de Comando e executar .venv\\Scripts\\activate.bat. Não altere políticas de segurança do sistema sem entender o motivo.

macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
3

Instale as bibliotecas

Com o ambiente virtual ativado, instale o SDK oficial do provedor de IA escolhido e a biblioteca para carregar variáveis de ambiente.

Terminal
python -m pip install openai python-dotenv

Este exemplo usa o SDK Python da OpenAI e a API de respostas. Confira a documentação atual antes de adaptar para outro provedor: documentação da API.

4

Configure sua chave com segurança

No painel do provedor, crie uma chave de API. Na pasta do projeto, crie um arquivo chamado .env e coloque sua chave nele:

Arquivo .env
OPENAI_API_KEY=sua_chave_aqui

Substitua pelo valor real, sem aspas. Crie também um arquivo .gitignore com este conteúdo:

Arquivo .gitignore
.env
.venv/
__pycache__/

Não compartilhe esses arquivos. Se uma chave for exposta, revogue-a no painel e crie outra.

5

Faça a IA conversar por texto

Crie main.py. O primeiro protótipo recebe texto digitado, envia à IA e imprime a resposta. Use o código completo na seção Código inicial. Execute:

Terminal
python main.py

Digite uma pergunta e veja se a resposta aparece. Se ocorrer erro de autenticação, confira o arquivo .env e se a variável foi carregada.

6

Adicione uma voz de saída

Para começar sem configurar microfone, use a leitura de texto do sistema ou uma biblioteca de TTS. Uma opção simples é instalar pyttsx3, que usa vozes instaladas no sistema:

Terminal
python -m pip install pyttsx3

O exemplo completo de voz está abaixo. A qualidade e as vozes disponíveis variam por sistema operacional. Serviços de voz online podem soar mais naturais, mas enviam áudio ou texto a terceiros.

7

Adicione reconhecimento de voz

Depois que o modo de texto funcionar, instale uma biblioteca de captura e reconhecimento de fala, por exemplo SpeechRecognition. O suporte ao microfone pode exigir dependências adicionais do sistema. Teste a gravação e o reconhecimento em um arquivo separado antes de integrar.

Instalação inicial
python -m pip install SpeechRecognition

O reconhecimento online pode enviar o áudio para um serviço externo. Leia as condições de privacidade e avise outras pessoas antes de gravar em ambientes compartilhados.

8

Crie habilidades e teste com cuidado

Implemente cada habilidade como uma função Python específica: informar a hora, abrir um site permitido, guardar uma nota ou abrir um aplicativo conhecido. Para enviar mensagens, apagar arquivos, instalar programas ou fazer compras, exija confirmação humana — e evite automatizar ações irreversíveis.

Não use eval(), não passe a resposta da IA diretamente para o terminal e não permita que o modelo execute qualquer comando que inventar.

04 / Código funcional inicial

O cérebro do JARVIS

Este é um protótipo por texto com respostas da IA. Primeiro faça esta versão funcionar; depois adicione voz. O modelo precisa estar disponível para sua conta e pode ser trocado conforme a documentação do provedor.

main.py — versão de texto
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()
api_key = os.getenv("OPENAI_API_KEY")

if not api_key:
    raise RuntimeError(
        "Chave não encontrada. Confira o arquivo .env."
    )

client = OpenAI(api_key=api_key)

INSTRUCOES = """
Você é JARVIS, um assistente pessoal educado, objetivo e útil.
Responda em português brasileiro.
Se não souber algo, admita. Não diga que executou ações
no computador se nenhuma ferramenta realmente as executou.
Não peça nem revele senhas, chaves privadas ou dados secretos.
"""

historico = []

def perguntar(texto):
    historico.append({"role": "user", "content": texto})

    resposta = client.responses.create(
        model="gpt-4.1-mini",
        instructions=INSTRUCOES,
        input=historico
    )

    texto_resposta = resposta.output_text
    historico.append({
        "role": "assistant",
        "content": texto_resposta
    })

    # Limita o histórico para não crescer sem controle.
    del historico[:-20]
    return texto_resposta

def main():
    print("JARVIS iniciado. Digite 'sair' para encerrar.")
    while True:
        try:
            mensagem = input("\\nVocê: ").strip()
            if mensagem.lower() in {"sair", "encerrar", "tchau"}:
                print("JARVIS: Até mais!")
                break
            if not mensagem:
                continue
            print("\\nJARVIS:", perguntar(mensagem))
        except KeyboardInterrupt:
            print("\\nJARVIS encerrado.")
            break
        except Exception as erro:
            print(f"\\nOcorreu um erro: {erro}")
            print("Confira internet, chave, saldo/limites e modelo.")

if __name__ == "__main__":
    main()
Sobre o modelo: gpt-4.1-mini é apenas um exemplo. Se não estiver disponível para sua conta ou tiver sido substituído, escolha um modelo compatível listado na documentação atual. A API pode gerar custos.

Como executar

  1. Salve o arquivo como main.py.
  2. Confira se o ambiente virtual está ativado.
  3. Confirme que o arquivo .env está na mesma pasta.
  4. Execute python main.py.
  5. Digite uma pergunta; use sair para fechar.

Como a conversa funciona

O programa guarda uma parte das mensagens anteriores em memória para dar contexto. Ao fechar o programa, o histórico desaparece. Não salve conversas sensíveis sem uma razão clara e medidas de proteção.

Dar voz ao assistente

Instale a biblioteca e adicione uma função de fala ao arquivo. Depois, substitua a impressão da resposta por uma chamada a falar(resposta).

Trecho de voz — pyttsx3
import pyttsx3

voz = pyttsx3.init()
voz.setProperty("rate", 175)  # velocidade aproximada

def falar(texto):
    voz.say(texto)
    voz.runAndWait()

# Exemplo:
# resposta = perguntar("Explique o que é uma IA.")
# print("JARVIS:", resposta)
# falar(resposta)

Coloque o trecho no mesmo arquivo (depois de instalar pyttsx3). Inicialize a voz uma vez, não a cada mensagem. Se não houver voz ou surgir erro, verifique as vozes instaladas no sistema e teste apenas a função de fala.

05 / Próximas melhorias

Como transformar o protótipo em assistente

Evite tentar fazer tudo no primeiro dia. Uma arquitetura organizada facilita depuração e segurança.

Fase A — ouvir

Capture áudio apenas depois de iniciar por um botão ou palavra de ativação. Mostre quando o microfone estiver ativo e permita desligá-lo facilmente.

Fase B — entender

Converta áudio em texto, mostre o que foi reconhecido e peça confirmação quando a interpretação estiver incerta.

Fase C — agir

Crie uma lista fechada de ferramentas, com parâmetros validados e permissões mínimas. A IA escolhe entre ferramentas aprovadas; ela não recebe acesso total.

Fase D — memória

Guarde somente preferências não sensíveis e úteis, com opção de visualizar e apagar. Para persistência, use um banco local como SQLite.

Fase E — interface

Monte uma janela com estado do sistema, transcrição, resposta e botão de microfone. Tkinter é uma opção simples para começar.

Fase F — integrações

Calendário, casa inteligente e notificações exigem APIs próprias, autenticação e permissões. Integre uma de cada vez e teste em ambiente seguro.

06 / Segurança e privacidade

Regras que não devem ser ignoradas

Faça sempre

  • Guarde chaves no .env e fora do Git.
  • Use limites de gasto e acompanhe o uso da API.
  • Peça confirmação antes de ações importantes.
  • Valide nomes de arquivos, caminhos e argumentos.
  • Mostre quando o microfone estiver gravando.
  • Registre erros sem registrar segredos.

Nunca faça

  • Publicar a chave em HTML ou JavaScript no navegador.
  • Executar diretamente texto gerado pela IA no terminal.
  • Dar acesso irrestrito a arquivos, câmera ou microfone.
  • Deixar gravação contínua oculta.
  • Permitir exclusão, envio ou compra sem confirmação.
  • Tratar a resposta da IA como sempre correta.
Regra de ouro: a IA sugere; o seu programa valida; você autoriza. A chave da API deve ficar no computador/servidor, nunca em uma página pública. Se criar uma interface web, faça as chamadas à IA pelo backend.
09 / Evolução do projeto

Plano de desenvolvimento: iniciante ao avançado

Este roteiro ajuda a dividir o projeto em entregas pequenas e testáveis, em vez de tentar criar tudo de uma vez.

Nível 1 · Base

Assistente por texto

Python, API, prompt de sistema, histórico limitado e tratamento de erros.

Pronto quando: responde de forma consistente e encerra sem travar.

Nível 2 · Voz

Ouvir e falar

Entrada por microfone, transcrição visível, fala sintetizada e botão para cancelar.

Pronto quando: você consegue interromper e corrigir uma transcrição.

Nível 3 · Ferramentas

Habilidades seguras

Hora, notas, abrir sites conhecidos e outras funções explicitamente permitidas.

Pronto quando: argumentos inválidos são recusados e ações sensíveis pedem confirmação.

Nível 4 · Memória

Preferências persistentes

Armazenamento local, opção de consultar/apagar memórias e dados mínimos.

Pronto quando: o usuário entende o que é guardado e consegue excluir.

Nível 5 · Interface

Painel de controle

Janela com histórico, estado do microfone, erros, configurações e interruptor geral.

Pronto quando: o assistente pode ser desligado rapidamente.

Nível 6 · Integrações

Serviços externos

Calendário, domótica, notificações e outras APIs com permissões limitadas.

Pronto quando: tokens são protegidos e cada integração tem testes próprios.

10 / Diagnóstico

Checklist quando algo dá errado

Antes de mudar várias coisas ao mesmo tempo, verifique os itens abaixo em ordem.

O programa nem inicia

  • Confira a versão do Python.
  • Ative o ambiente virtual.
  • Veja se instalou as bibliotecas no ambiente correto.
  • Leia a primeira mensagem de erro completa.

A IA não responde

  • Verifique a internet e o estado do serviço.
  • Confirme que a chave está no ambiente, sem compartilhá-la.
  • Confira acesso ao modelo, limites e cobrança.
  • Teste uma pergunta curta.

O áudio não funciona

  • Confira dispositivo de entrada/saída do sistema.
  • Teste microfone fora do programa.
  • Confira permissões de privacidade do sistema.
  • Teste voz e reconhecimento separadamente.
Ao pedir ajuda com um erro: compartilhe a mensagem de erro e o sistema operacional, mas remova chaves de API, senhas, tokens, endereços privados e outros dados pessoais.

08 / Dúvidas frequentes

Se algo não funcionar

“python” não é reconhecido no terminal

No Windows, tente py --version. Se funcionar, use py nos comandos. Caso contrário, reinstale Python pelo site oficial e habilite a opção de PATH. Feche e reabra o terminal depois da instalação.

Erro de chave ou autenticação

Confirme se o arquivo se chama exatamente .env, se está ao lado do main.py e se a linha é OPENAI_API_KEY=.... Confira se a chave está ativa e se a conta tem acesso à API. Não envie sua chave para ninguém diagnosticar o erro.

Erro de limite, saldo ou modelo

Confira o painel de uso, os limites da conta e os modelos disponíveis para sua API. ChatGPT e API são produtos com cobrança e acesso separados em muitos casos; ter assinatura do ChatGPT não significa automaticamente ter crédito na API.

Posso fazer tudo sem internet?

Sim, usando um modelo local compatível e ferramentas locais, mas a instalação, a velocidade e a qualidade dependem do hardware. Um modelo local não precisa enviar cada pergunta a um provedor externo, mas você ainda deve cuidar dos dados e permissões.

Como fazer o JARVIS abrir programas?

Crie funções explícitas para os aplicativos que você confia, com caminhos conhecidos e validação. Não crie uma função genérica que execute qualquer comando recebido da IA. Teste primeiro com ações inofensivas.

Ele vai ser igual ao JARVIS do filme?

Não de início. O projeto ensina os componentes reais por trás de um assistente: linguagem, voz, ferramentas e automação. Recursos avançados exigem engenharia, testes, hardware e integração de vários serviços.

09 / Transforme uma IA em JARVIS

Como transformar ChatGPT, Claude ou outra IA no cérebro do seu assistente

Você não precisa criar um modelo gigantesco do zero. O caminho mais prático é usar um modelo já treinado como cérebro e conectá-lo ao seu programa, à voz e a ferramentas que você controla. O ChatGPT ou o Claude aberto no navegador não se transforma automaticamente no JARVIS: seu programa precisa se conectar ao modelo por uma API ou por uma integração oficialmente suportada.

Ideia principal: modelo de IA + instruções de personalidade + memória controlada + ferramentas autorizadas + voz = assistente no estilo JARVIS. A IA conversa e decide qual ferramenta aprovada pode ajudar; seu código executa e valida a ação.
🧠

Opção A — usar uma API

Seu programa Python envia mensagens a um modelo na nuvem. É a opção mais simples para obter respostas de boa qualidade, mas exige internet, uma chave de API e pode ter custos.

💻

Opção B — modelo local

Executa um modelo no seu próprio computador usando ferramentas como Ollama. Pode melhorar o controle dos dados e reduzir dependência de serviços online, mas velocidade e qualidade dependem do hardware.

🔌

Opção C — integrar uma plataforma existente

Use APIs ou integrações oficiais disponíveis no serviço escolhido. Uma assinatura do chat no navegador não garante acesso à API nem cobre seu consumo: confira as condições do provedor.

Passo a passo: conecte um modelo existente

Este fluxo serve como mapa geral para ChatGPT/OpenAI, Claude/Anthropic ou outros provedores. Os nomes dos pacotes, formatos de mensagens e recursos variam conforme a API.

1

Escolha o modelo e a forma de acesso

Decida se vai usar uma API hospedada ou um modelo local. Para uma API, crie uma conta no portal de desenvolvedores do provedor e confira modelos disponíveis, preços, limites, política de dados e documentação oficial.

OpenAI: documentação da API. Anthropic/Claude: documentação da API. Modelo local: Ollama.

2

Crie uma camada de IA separada

Não misture tudo no mesmo bloco de código. Crie uma função, por exemplo perguntar_ia(mensagem, historico), que recebe a mensagem, chama o provedor escolhido e devolve o texto da resposta. Assim, você pode trocar o modelo sem reescrever voz, interface ou habilidades.

O exemplo main.py deste site já faz isso para uma API da OpenAI. Para Claude, substitua a chamada pelo SDK oficial da Anthropic e siga o formato da documentação. Não basta trocar o nome do modelo: APIs diferentes podem ter parâmetros e estruturas diferentes.

3

Dê uma identidade consistente ao assistente

Defina instruções de sistema claras: nome, idioma, tom, limites, o que pode fazer e quando deve admitir que não sabe. Isso orienta o comportamento, mas não altera nem treina os pesos do modelo.

Exemplo de instruções
PERSONALIDADE_JARVIS = """
Você é JARVIS, assistente pessoal do usuário.
Fale em português brasileiro, com calma, clareza e precisão.
Seja prestativo, organizado e ligeiramente espirituoso, sem exagerar.
Explique antes de executar uma ação importante.
Nunca afirme que fez algo se o programa não confirmou a execução.
Não invente resultados, não revele segredos e peça esclarecimentos
quando o pedido for ambíguo.
Só use ferramentas explicitamente disponibilizadas pelo programa.
Para ações que alterem arquivos, enviem mensagens ou gerem gastos,
descreva a ação e peça confirmação antes de continuar.
"""

Coloque as instruções no campo apropriado da API. Não as publique como segredo: elas definem o comportamento, mas a chave da API é que deve ser protegida.

4

Adicione memória com limites

O histórico de conversa permite que a IA acompanhe o assunto durante uma sessão. Para lembrar preferências entre sessões, crie uma memória separada, com consentimento e opção de apagar. Salve apenas o necessário, como “prefere respostas curtas”; evite senhas, chaves, documentos privados e gravações desnecessárias.

Importante: a memória não é a mesma coisa que treinar o modelo. Ela fornece contexto adicional nas próximas conversas. Comece com memória temporária e só depois adicione armazenamento local.

5

Ensine o JARVIS a usar ferramentas

Uma IA em conversa normal não controla seu PC por mágica. Você precisa programar ferramentas específicas e descrever para o modelo o que cada uma faz. Exemplos: ver_hora(), abrir_site_aprovado(nome) e criar_nota(texto).

O fluxo correto é: a IA solicita uma ferramenta estruturada → seu programa verifica nome e parâmetros → pede confirmação se a ação for sensível → executa uma função permitida → devolve o resultado à IA para formular a resposta. Implemente chamadas de ferramenta usando o recurso oficial da API escolhida; a sintaxe é diferente entre provedores.

6

Conecte entrada e saída de voz

Use reconhecimento de fala para converter sua voz em texto e texto-para-fala para ler a resposta. Primeiro, faça o modo de texto funcionar. Depois conecte microfone e alto-falante. Mostre um indicador quando o microfone estiver ativo e ofereça um botão para interromper a escuta.

7

Crie uma interface de assistente

Uma janela pode mostrar o que o microfone reconheceu, a resposta da IA, as ferramentas usadas e um botão para cancelar. Você pode começar com Tkinter, depois evoluir para uma aplicação web local. Se criar um site público, nunca coloque a chave da API no código do navegador: faça as chamadas pelo backend.

8

Teste antes de confiar

Teste perguntas simples, comandos ambíguos, falta de internet, API fora do ar e respostas erradas. Simule ferramentas primeiro, sem realmente alterar arquivos ou enviar mensagens. Registre erros sem guardar chaves nem dados sensíveis. Só libere cada ação depois de validar seus limites.

Exemplo de arquitetura com ferramentas

Este é um pseudocódigo para entender o fluxo, não um programa pronto para executar. A chamada de ferramenta exata depende do provedor.

Fluxo seguro
mensagem = ouvir_ou_ler_usuario()
resposta_ou_pedido = perguntar_ia(mensagem, historico)

if resposta_ou_pedido.solicita_ferramenta:
    ferramenta = encontrar_em_lista_permitida(
        resposta_ou_pedido.nome
    )
    argumentos = validar_argumentos(
        ferramenta, resposta_ou_pedido.argumentos
    )

    if ferramenta.acao_sensivel:
        pedir_confirmacao_humana()

    resultado = executar_apenas_ferramenta_aprovada(
        ferramenta, argumentos
    )
    resposta_final = perguntar_ia_com_resultado(
        mensagem, resultado, historico
    )
else:
    resposta_final = resposta_ou_pedido.texto

mostrar_resposta(resposta_final)
falar_se_ativado(resposta_final)
Não faça isto: não envie a resposta livre da IA para os.system(), subprocess ou um terminal. Isso pode executar comandos perigosos ou inventados. Use uma lista fechada de ferramentas, valide os argumentos e peça autorização para operações importantes.
